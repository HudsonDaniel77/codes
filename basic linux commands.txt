For **Part B**, you need a C program where:

- The user enters a command: `ls`, `cal`, `uname`, or `date`
- The **child process** executes the command using `exec()`
- The **parent process** waits using `wait()`
- The program prints the **process ID (PID)** for each command

### C Program

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>

int main() {
    char command[20];
    pid_t pid;

    printf("Enter command (ls/cal/uname/date): ");
    scanf("%s", command);

    pid = fork();

    if (pid < 0) {
        printf("Fork failed\n");
        return 1;
    }

    if (pid == 0) {
        // Child process
        printf("Child Process ID: %d\n", getpid());

        if (strcmp(command, "ls") == 0)
            execlp("ls", "ls", NULL);

        else if (strcmp(command, "cal") == 0)
            execlp("cal", "cal", NULL);

        else if (strcmp(command, "uname") == 0)
            execlp("uname", "uname", NULL);

        else if (strcmp(command, "date") == 0)
            execlp("date", "date", NULL);

        else
            printf("Invalid command\n");

        exit(1);
    }

    else {
        // Parent process
        wait(NULL);
        printf("Parent Process ID: %d\n", getpid());
        printf("Child Process ID: %d completed\n", pid);
    }

    return 0;
}
```

**Important:** Add this header because `strcmp()` is used:

```c
#include <string.h>
```

So the complete header section is:

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <string.h>
```

Save as `process.c`:

```bash

```

Run:

```bash
./process
```

### How it works

```text
             Parent Process
                  |
                fork()
               /      \
              /        \
       Child Process   Parent Process
            |                |
         exec()            wait()
            |                |
      ls/cal/uname/date      |
            |                |
            └──────→ completes
```

**Key functions to remember for the exam:**

- `fork()` → creates a child process
- `getpid()` → gets process ID
- `execlp()` → replaces child process with the requested command
- `wait()` → parent waits for child to finish
- `exit()` → terminates the process

```text
ls
```

your program should create a child process, and the **child process executes `ls`**.

---

# 2. Why do we need `fork()`?

`fork()` creates a new process.

Before `fork()`:

```text
        Program
          |
       Parent
```

After `fork()`:

```text
        Program
          |
     ┌────┴────┐
     ↓         ↓
  Parent      Child
```

The parent and child are now separate processes.

The important thing is:

```c
pid = fork();
```

After this:

```c
pid > 0
```

means you are in the **parent**.

```c
pid == 0
```

means you are in the **child**.

```c
pid < 0
```

means `fork()` failed.

---

# 3. Why does the child need `exec()`?

The child created by `fork()` initially contains a copy of the same program.

But we don't want the child to continue executing our C program.

We want it to become:

```text
ls
```

or

```text
cal
```

or

```text
uname
```

or

```text
date
```

That's what `exec()` does.

For example:

```c
execlp("ls", "ls", NULL);
```

This tells the child:

> Replace the current child program with the `ls` program.

Similarly:

```c
execlp("cal", "cal", NULL);
```

runs `cal`.

```c
execlp("uname", "uname", NULL);
```

runs `uname`.

```c
execlp("date", "date", NULL);
```

runs `date`.

---

# 4. Why does the parent need `wait()`?

Suppose the child is executing:

```bash
ls
```

The parent shouldn't immediately finish.

We want:

```text
Parent
  |
 wait()
  |
  |------ Child runs ls
  |              |
  |              ↓
  |           finishes
  ↓
Parent continues
```

Therefore:

```c
wait(NULL);
```

makes the parent wait until the child finishes.

---

# 5. What does "print the process ID" mean?

Every process has a unique **Process ID (PID)**.

We can obtain the current process's PID using:

```c
getpid()
```

For example:

```c
printf("Child PID = %d\n", getpid());
```

If the child PID is `12345`, you'll see:

```text
Child PID = 12345
```

The parent can also print its PID:

```c
printf("Parent PID = %d\n", getpid());
```

# 6. Complete program

This is a good exam-ready version:

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <string.h>

int main() {
    char command[20];
    pid_t pid;

    printf("Enter command (ls/cal/uname/date): ");
    scanf("%s", command);

    pid = fork();

    if (pid < 0) {
        printf("Fork failed\n");
        return 1;
    }

    if (pid == 0) {
        // Child process

        printf("Child PID: %d\n", getpid());

        if (strcmp(command, "ls") == 0)
            execlp("ls", "ls", NULL);

        else if (strcmp(command, "cal") == 0)
            execlp("cal", "cal", NULL);

        else if (strcmp(command, "uname") == 0)
            execlp("uname", "uname", NULL);

        else if (strcmp(command, "date") == 0)
            execlp("date", "date", NULL);

        else
            printf("Invalid command\n");

        exit(1);
    }

    else {
        // Parent process

        wait(NULL);

        printf("Parent PID: %d\n", getpid());
        printf("Child process completed\n");
    }

    return 0;
}
```

# 14. Most important concept for your exam

Memorize this structure:

```c
pid = fork();

if (pid == 0) {
    // CHILD

    printf("PID = %d", getpid());

    execlp(...);
}
else {
    // PARENT

    wait(NULL);

    printf("Parent completed");
}
```

The logic is:

```text
              fork()
                |
       ┌────────┴────────┐
       ↓                 ↓
     CHILD             PARENT
       |                 |
   getpid()            wait()
       |                 |
     exec()              |
       |                 |
  ls/cal/uname/date      |
       |                 |
       └──── finishes ───┘
```

### The four functions you absolutely need to understand

| Function | Purpose |
|---|---|
| `fork()` | Creates child process |
| `getpid()` | Gets current process ID |
| `exec()` / `execlp()` | Executes another program |
| `wait()` | Parent waits for child |

**One correction to the wording of your question:** technically, `exec()` does not "create" the child process. **`fork()` creates the child; `exec()` replaces the child's program with the requested command.** This distinction is worth remembering because it is a common OS viva question.
